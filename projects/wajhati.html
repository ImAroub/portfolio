Wajhati

Full-Stack Travel Planning Web Application

Wajhati helps users plan trips within Saudi Arabia by generating customizable day-by-day itineraries that combine attractions, restaurants, and cafés.

View on GitHub

Overview

Wajhati is an Arabic travel-planning application designed to simplify domestic trip planning and reduce the need to search for places and organize daily schedules manually.

Users select a destination city and trip duration, and the system generates an initial itinerary using available attractions, restaurants, and cafés. The current version supports Riyadh and Jeddah.

My Role

I developed Wajhati as an individual project during an ASP.NET Core MVC training program at Tuwaiq Academy.

I built the application end to end, including the MVC architecture, application logic, database design and integration, authentication and user accounts, trip generation and customization, saved trips, place management, image uploads, and the user interface.

Explore the Application

Users can explore destinations before building a trip, with searchable and filterable place information.

How Wajhati Works

The trip-planning flow moves from a simple destination selection to a generated itinerary that remains fully customizable.

01

Choose a Destination

After signing in, the user selects a destination city and a trip duration from one to seven days.

02

Generate an Itinerary

Wajhati creates a day-by-day itinerary using places available in the selected city. Each day typically includes a main destination, a restaurant, and a café while avoiding repeated places when alternatives are available.

03

Customize & Save

The generated plan remains editable. Users can add or remove places, edit individual days, add new days, and save the completed trip to their account for later access.

Key Features

Explore & Search

Browse detailed place information and search or filter destinations by name, city, and category.

Itinerary Generation

Generate multi-day trip plans using available attractions, restaurants, and cafés for the selected city.

Customizable Trips

Modify generated itineraries by managing individual days and adding or removing destinations.

Content Management

Manage place records, descriptions, opening hours, booking requirements, links, and uploaded images through the application.
